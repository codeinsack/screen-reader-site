What it is

Read Aloud is a Chrome extension that turns text on websites and in PDFs into speech. Use it as a screen reader and voice narrator for articles, docs, and long pages — without leaving the tab you are on.

How to use

  1. Install the extension from the Chrome Web Store and pin it to the toolbar for quick access.
  2. Open any webpage. Click the Read Aloud icon to open the popup.
  3. Select text on the page, paste from the clipboard, load a PDF, or use Read entire page to capture the main content.
  4. Pick a voice (or enable Auto-detect language), then press Play. Use pause, previous/next sentence, or stop as needed.

Features

Web & PDF

Read selected text, pasted text, whole pages, or text extracted from PDF files.

Voices & languages

Search voices by name, language, or gender. Auto-detect helps match the text language.

Playback controls

Play, pause, stop, and jump between sentences for comfortable listening.

Clipboard

Paste text from anywhere — handy for emails, notes, or other apps.
